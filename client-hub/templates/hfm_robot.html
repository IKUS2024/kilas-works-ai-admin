Robot Trading

GPT-6.2 Sol menilai sinyal emas dari MT5. Robot dapat membuka posisi 0,01 lot ketika analisis menyetujui arah dan Algo Trading aktif.

Pasang di MT5 HFM Cent

  1. Unduh robot dan salin ke MQL5/Experts melalui File → Open Data Folder.
  2. Masukkan nomor akun pada bagian koneksi. Simpan file koneksi ke MQL5/Files di terminal yang sama.
  3. Di Tools → Options → Expert Advisors, izinkan WebRequest ke https://trading.kilasworks.id.
  4. Refresh Expert Advisors di Navigator, pasang robot di chart XAUUSDc pada HFMarketsGlobal-Live12, lalu nyalakan Algo Trading saat siap.
