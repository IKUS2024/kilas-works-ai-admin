## Verified defects and fixes

- Short mathematical proofs, equations, integrals, probability and recurrences previously received the general NORMAL profile. Selected Chat now recognizes these tasks and contextual follow-up corrections, keeps the exact selected model (managed Luna), and uses the existing DEEP/high profile. Guidance asks for a checkable derivation, assumptions/domain, substitution or boundary checks, exact/approximate distinction and counterexamples to false premises. It forbids invented execution and correctness guarantees. Legacy/autonomous routing is unchanged.
- Explicit brevity previously forced low reasoning even for difficult selected Chat. Difficulty now chooses effort independently from visible answer length. Brief difficult answers have an 8,192 total completion-token ceiling (the existing STANDARD budget), ordinary difficult answers 16,384, and the existing maximum remains 24,576. This can increase actual usage for these requests; existing reservations, metering, rate limits and billing rules still apply. No unlimited budget or forced word count was added.
- Valid Markdown tables without optional outer pipes rendered as prose; table alignment was discarded. Both forms now produce accessible scroll regions, header cells and aligned columns during streaming and after completion. Code/TeX pipes remain protected, HTML stays inert, and copied source remains exact. This changes only answer rendering, not the composer or global styles.
- Image-option parsing treated “jangan transparan”, “not transparent” and later opaque corrections as requests for transparency. Negation and the last explicit transparency preference now determine the option. Native high-quality 2048×2048 default, requested dimensions/ratio, Sunburst selection, source bytes, one-image behavior, reference isolation and no-fallback policy remain intact.
