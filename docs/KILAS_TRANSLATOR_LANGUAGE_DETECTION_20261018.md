Classic first/source picker now offers Detect language / Deteksi bahasa / Detectar idioma / 检测语言. Selecting it uses complete-recording batch Scribe v2, whose real `language_code` and `language_probability` fields are retained. Detection never comes from a guessed downstream code. Documented ISO639-3 response IDs normalize before route validation. The app's conservative confidence threshold is0.7, not a provider accuracy guarantee. Missing/low confidence, unsupported source or source equal to the required target returns a localized actionable error before translation/TTS. A reversed LLM output is also rejected before TTS. Existing metering retains a dispatched ASR operation; no automatic paid retry occurs. Explicit two-way pairs retain their existing behavior and voices. Auto is one-way toward the selected target, and is not counted as an84th language.
