## Changes and preservation

- Processing POST admits a bounded background job and returns202/status_url. Short owned GETs return bounded versioned snapshots. The HTTP worker never waits for a provider stream; production retains its existing single sync worker. Max2 provider jobs per process, max32 memory snapshots, completed snapshot TTL300s, no raw audio in the registry. This is intentionally not a multi-worker/distributed queue. Lease/worker identity and durable operation rows expose interruption after restart without replaying audio.
- Mic/CTA still share one guarded handler: first tap requests browser permission/captures, second stops and submits. No TTS, typed-input mode, interim fake transcript, auto-rearm or automatic paid submission. Feedback and progressive text use short polls. Cancel/offline/navigation close local capture and send a durable fence; already-dispatched provider IO may still finish/use cost.
- TurnControl uses a120second monotonic turn budget with bounded connect/read timeouts. Guarded SSE reads check even comments and unterminated byte trickles; no unlimited heartbeat stream. The current socket read may finish at its bounded idle timeout after cancellation/deadline. No claim that cancellation reverses provider billing.
- A completed primary reply is persisted before optional translation. Failure/cancellation retains that reply/source and records a translation-specific status. One explicit Retry translation creates an idempotent metered operation using stored source/reply; it does not call STT or regenerate the primary. Retry cannot run against another owner or an already-translated turn; repeated keys do not dispatch twice. A late cancel serializes with translation commit. No successful partial primary is fabricated.
- Appending optional stage data preserves the same primary/history turn, not a duplicate reply. Durable completed rows recover when snapshot memory expires; old interrupted primary rows remain readable and explicitly recoverable after restart. Existing AI Chat implementation/routes/data remain hidden and retained; existing histories are not purged.
- Source speech is explicitly other-speaker/unattributed evidence. First-person facts from the other speaker cannot become the listener's school/job/identity. Personal unknowns retain localized fill-yourself slots. Latest corrections win; earlier source retrieval and head+tail excerpts fit the existing24KB request budget. Recent suggestions stay labeled unconfirmed. History/model context remain bounded (latest200 nonempty messages); this is not unlimited recall or an automatically verified biography.
- Reply provider/model/effort/token cap remain OpenAI/gpt-6-luna/low/1024. No upgrade or fallback added. Audio path remains PCM mono16-bit/16kHz WAV, worklet/fallback/flush and60second cap. Heavy clipping (>25% near-full-scale samples) is rejected before billing; quiet/sparse speech remains admitted. A server-measured duration-cap hint asks the reply model not to invent a cut-off ending. Noise suppression is a browser request, not recognition confidence or a guarantee of perfect transcription.
- Five repeated status SELECTs became one joined owned query; provider-byte/delta cancellation checks share a250ms polling window with forced checks at stage/commit boundaries. Versioned unchanged UI snapshots do not redraw/select-copy text repeatedly.
- Existing0.18USD conservative SMART envelope remains. Per-stage numeric usage/timings are recorded without audio/provider identifiers. Known text tokens populate ledger counters; costs remain labeled estimates because STT/all-provider final cost is not independently known. A valid primary promotes operation completion even if optional translation fails. No guessed refund, free bypass, allowance increase or false actual-cost claim.
- Translation toggle, target and tone persist in the owned session marker; reload/app-locale changes retain controls. New sessions remain micOFF. UI locale never changes original speech/primary reply language. New failure/retry/timeout labels have EN/ID/ES/ZH entries.
- Small result CTA uses local dark-orange background for normal-text contrast; idle layout and brand remain. Privacy documentation explains saved primaries, explicit retry admission and conservative estimates. No Info panel restored. Finance and Translator/VO engines/core controls unchanged. The optional provider transport guard defaults off for all existing callers.

A new model ID alone is not a migration. This remains a dated follow-up before shutdown, not a claim the active provider is broken today.
